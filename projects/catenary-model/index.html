Open-source model

A catenary model for mooring lines

Explore the geometry of a hanging mooring line between reference points.

  • JavaScript
  • Catenary geometry
  • Plotting

Engineering purpose

A suspended line takes a catenary shape under its own weight. Plotting that geometry makes an important mooring concept tangible.

My contribution

The public demonstration is credited to me in its interface and maintained in my ferrari212/mooring repository. It is a separate, focused example alongside the collaborative floating-body simulations.

Methods and implementation

JavaScript and Flot plotting are used to represent the hanging line between reference points. The linked source provides the model and interface implementation.

Demonstrated capability

The demonstration turns a geometric model into a visual experiment. It illustrates line shape; it should not be confused with a complete coupled mooring dynamics solver.

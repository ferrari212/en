## Engineering purpose
A manoeuvring model connects a vessel’s controls with its motion. An interactive interface makes that relationship easier to explore than a set of equations alone.

## My contribution
At NTNU, I contributed to browser-based navigation and vessel simulation tools using digital vessel models and operational context. This demonstration belongs to the collaborative ShipLab body of work; it is not presented as a solely authored platform.

## Methods and implementation
JavaScript connects the numerical model to an interactive visualization. The interface allows visitors to explore the response to configuration and control inputs.

## Demonstrated capability
An engineering model can become an accessible, interactive experiment in a web browser. The linked demonstration and source provide the implementation context; this portfolio does not claim validation for operational navigation.
